## Overview
This microservice provides RESTful APIs for managing Customer Accounts with built-in:
- Test-Driven Development (TDD) with nosetests
- Security headers using Flask-Talisman
- Cross-Origin Resource Sharing (CORS) using Flask-Cors
- Containerization using Docker
- Automated CI pipeline using GitHub Actions
- Automated CD pipeline using Tekton and Kubernetes
